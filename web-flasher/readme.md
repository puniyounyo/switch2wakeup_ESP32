# Switch 2 Wakeup - Web Flasher & Configurator

ESP32-C3 を使って、プロコン（Nintendo Switch Pro Controller）から Nintendo Switch 2 を起動するための装置を、**ブラウザだけで**セットアップするツールです。

ファームウェアの書き込みから、ペアリング情報（MACアドレス / PID）の取得・設定までを、Arduino IDE なしで行えます。

## できること

1. **スキャナー**: 周辺の Nintendo デバイスを BLE でスキャンし、Joy-Con と Switch 2 のMACアドレス・PIDを検出します。
2. **送信機**: 送信機用ファームを書き込み、検出した情報を設定として ESP32 に転送します。

## 必要なもの

- ESP32-C3 ボード × 1〜2（スキャナー用と送信機用。1枚を書き換えて使い回しても構いません）
- USB ケーブル（データ通信対応のもの）
- **Chrome または Edge**（Web Serial API が必要です。Firefox / Safari は非対応）
- 次の3ファイルを**同じフォルダ**に置く

| ファイル | 内容 |
|---|---|
| `index.html` | 書込・設定ツール本体 |
| `BLE_Scanner.bin` | スキャナー用ファームウェア |
| `transmitter_web.bin` | 送信機用ファームウェア |

## 起動のしかた

`index.html` を直接ダブルクリックして開くと、`.bin` を読み込めません。**ローカルサーバー経由**で開いてください。

```bash
# 3つのファイルを置いたフォルダで実行
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

GitHub Pages などで公開する場合も、3ファイルを同じ場所に置けば動きます（HTTPS が必要です）。

## 使い方

### 1. スキャナーでペアリング情報を取得する（左側）

1. スキャナー用の ESP32 を USB 接続します。
2. **① ポート接続 (スキャナー)** を押し、ESP32 のポートを選びます。
3. **② BLE_Scanner.bin を書込** を押します。
4. 書込完了後、自動でリセットしてログの受信が始まります。
   - ログに何も出ない場合は、下の「[ログが出ないとき](#ログが出ないとき自動リセットが効かない場合)」を参照してください。
5. Nintendo デバイスが検出されると、**「検出されたNintendoデバイス」** の一覧に追加されます。
6. 一覧から目的の組み合わせを選び、**選択したペア情報を右側に一括転記** を押します。
   - 右側の Joy-Con MAC / Switch 2 本体 MAC / PID に値が入ります。

### 2. 送信機を書き込んで設定を送る（右側）

1. 送信機用の ESP32 を USB 接続します。
2. **① ポート接続 (送信機)** を押し、ポートを選びます。
3. **② transmitter_web.bin 書込 ＆ 自動再接続** を押します。
4. 書込後、ログに次のメッセージが出れば設定待ちの状態です。

   ```
   >>> [CONFIG MODE] Please send CFG:JC_MAC,SW_MAC,PID from Web UI.
   ```

5. Joy-Con MAC / Switch 2 本体 MAC / PID の値を確認し、**③ 設定送信 ＆ 完了** を押します。
6. 設定が送信されると、ESP32 が送信機として動作を始めます。

## ログが出ないとき（自動リセットが効かない場合）

ESP32-C3 の USB は、リセットのたびに再接続されます。ボードによっては、書込後の自動リセットが効かず、ログが何も出ないことがあります。その場合は次の手順で進めてください。

1. ESP32 の **RST ボタン**を押します。
2. USB が再接続されたら、**②' ポートを選び直す** を押します。
3. 新しく表示されたポートを選びます。

書込後4秒たっても ESP32 から何も届かない場合は、ログにこの手順が自動で表示されます。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| `.bin が見つかりません` と出る | `index.html` と同じフォルダに `.bin` があるか。`file://` ではなくサーバー経由で開いているか |
| ポートが選択肢に出ない | データ通信対応の USB ケーブルか。別の USB ポートで試す。他のアプリ（Arduino IDE のシリアルモニタ等）がポートを使用していないか |
| ESP32 に接続できない | ボードの BOOT ボタンを押しながら USB を接続し、ダウンロードモードで再試行する |
| 設定を送っても反応がない | 「詳細設定」で改行コードを確認する（既定は LF）。手動送信欄に `CFG:...` を入れて試す |
| 送信後に `CONFIG MODE` がもう一度出る | ESP32 が再起動している。「open後のDTR/RTS」は「触らない」のままにする |
| 検出一覧が空のまま | ログの `🔎 解析:` の行で、JC / SW / PID のどれが `-` のままか確認する |

## 設定データの形式

送信機には、次の形式の1行が送られます（改行は LF）。

```
CFG:<Joy-Con MAC>,<Switch 2 MAC>,<PID>
```

例:

```
CFG:AA:BB:CC:DD:EE:FF,11:22:33:44:55:66,0x2066
```

Arduino IDE のシリアルモニタ（改行コード: LF、ボーレート 115200）から同じ文字列を送っても設定できます。

## 仕組み

- 書込には [esptool-js](https://github.com/espressif/esptool-js) を使っています（CDN から読み込み）。
- 書込後は、DTR/RTS 信号でリセットをかけ、通常のシリアルとしてポートを開き直します。
- 送信機は「CONFIG MODE」の表示を受信したのを確認してから設定を送ります。起動直後の取りこぼしを避けるためです。
