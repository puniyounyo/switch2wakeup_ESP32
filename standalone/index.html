Switch 2 Wakeup 書き込み

ESP32-C3 にスタンドアローン版ファームウェアを書き込みます。書き込みは最初の1回だけ。以降はPCなしで設定を変更できます。

このブラウザは Web Serial に対応していません。PC の Chrome または Edge で開いてください。

ファームウェアを書き込む

ESP32 を USB でPCにつないでから、下のボタンを順に押します。

未接続

待機中...
接続できない場合は、ESP32 の BOOT ボタンを押したまま USB を差し直してから、もう一度「ポートを選んで接続」を押してください。 このページは file:// ではなく http://localhost か https のページとして開く必要があります。

書き込み後の流れ

  1. 書き込みが終わると ESP32 が再起動し、約15秒のあいだ LED が1秒に1回短く光ります。その後ディープスリープに入ります。
  2. ディープスリープに入るとUSBの接続は切れます。PCからデバイスが消えるのは正常です。
  3. この時点の設定はダミーMAC(AA:BB:CC:DD:EE:FF / 11:22:33:44:55:66)です。ホームボタンを押しても Switch 2 は起動しません。次の「Switch 2 の情報を登録する」を行ってください。

配線

GPIO4ホームボタン (押すとGNDに接続)
GPIO5設定用ボタン (今回はRボタン押し込み。押すとGNDに接続)

Switch 2 の情報を登録する

Joy-Con 2 と Switch 2 本体の MAC アドレスを、ESP32 が自分で聞き取って保存します。PC は使いません。

  1. Switch 2 本体をスリープ状態にします。
  2. 設定用ボタン(R)を押したまま、ホームボタンを押します。電源投入やリセットの瞬間に R を押したままにする方法でも同じです。
  3. LED が「ピピッ」と繰り返し光ればスキャナーモードです。動作時間は30秒です。
  4. 30秒以内に、ペアリング済みの Joy-Con 2 の任意のボタンを押します。本体から外す操作でも反応する場合があります。確実なのはボタンを押す方法です。
  5. 情報を受け取れると LED が2秒間点灯し、保存してスリープに入ります。
  6. ホームボタンを押して Switch 2 が起動すれば完了です。

30秒たっても見つからなかった場合は LED が5回素早く光り、設定は変わらないまま眠ります。Joy-Con 2 を ESP32 に近づけて、もう一度試してください。

LED の見かた

1秒に1回、短く光る起動直後の待機中(約15秒)
高速で点滅起動信号を送信中(2.5秒)
「ピピッ」を繰り返すスキャナーモード(30秒)
2秒間点灯登録成功
5回素早く点滅登録失敗(設定は変更なし)

困ったとき

  • もう一度書き込みたい: BOOT ボタンを押したまま USB を差し直すと、スリープ中でも書き込めます。リセットボタンを押した後の15秒間も接続できます。
  • 登録した情報を消したい: 結合された .bin を書き込み直すと、登録内容は初期状態(ダミーMAC)に戻ります。
  • シリアルモニタで確認したい: リセット後の15秒間に、115200bps で SHOW を送ると現在の登録内容が表示されます。CLR で初期状態に戻せます。
  • Switch 2 が起動しない: 登録後に Switch 2 側で Joy-Con 2 の登録を解除していないか確認してください。
