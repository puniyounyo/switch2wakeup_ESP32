ESP32-C3に、先ほど用意したArduino IDE用のBLEスキャナー（MACアドレスを拾うプログラム）を書き込んで実際に動かすまでの手順をまとめました。

📝 1. Arduino IDEの準備とコードの貼り付け
Arduino IDEを開く

新規のスケッチを作成し、先ほどのBLEスキャナーのコード（#include <BLEDevice.h> から始まるコード）をすべて貼り付けます。

コード内のLEDピンの番号（#define LED_PIN 2）が、お使いのESP32-C3ボードのLEDピンと合っているか確認します（多くのESP32-C3 SuperMiniや開発ボードでは 8 や 2 が使われますが、分からない場合はそのままでOKです）。

🔌 2. ESP32-C3を「書き込みモード」でPCに繋ぐ
先ほどお話しした「接続・切断のループ」を防ぐため、強制的に書き込み待機状態（ダウンロードモード）にしてからPCに接続します。

ESP32-C3ボード上の 「BOOT」ボタン（または「0」ボタン）を押したままにする。

そのままUSBケーブルをPCに挿す。

挿した後も 2〜3秒ほどボタンを押し続けたままにし、その後指を離す（これでPCとの接続音がピタッと止まり、書き込み待ち受け状態になります）。

⚙️ 3. Arduino IDEの設定確認
「ツール」メニューから、お使いのESP32-C3の環境設定が正しく選ばれているか確認します。

ボード: ESP32C3 Dev Module（または ESP32-C3 が含まれる項目）

USB CDC On Boot: Enabled（※ESP32-C3でシリアルモニタを使うために重要です）

Flash Mode: QIO または DIO

Port: ESP32-C3が繋がっているCOMポート（例: COM3 や /dev/cu.usbserial-...）

🚀 4. 書き込みと実行
Arduino IDEの画面上部にある 「マイコンボードへ書き込み」ボタン（→の矢印アイコン） をクリックします。

下部のコンソールに Connecting....... と出たら、もし書き込みが始まらない場合はボード上の BOOTボタンを一度だけ軽く押す と書き込みがスタートします。

書き込みが Hard resetting via RTS pin... と表示されて完了したら成功です！

🔍 5. シリアルモニタでMACアドレスを確認する
Arduino IDEの右上にある 「シリアルモニタ」アイコン をクリックします。

ボーレート（通信速度）が 115200 になっていることを確認します。

スイッチ2側でコントローラー接続画面（「コントローラー」＞「持ち方/順番を変える」など）を開き、ESP32-C3を本体の数センチの距離に近づけてしばらく待ちます。

周囲のNintendoデバイスやターゲットがスキャンされると、シリアルモニタに ★ [NINTENDO FOUND!] MAC: XX:XX:XX:XX:XX:XX のように目的のMACアドレスがズラッと表示されます！

まずはこの手順で、Switch 2（または周辺機器）のMACアドレスの特定からやってみましょう！
